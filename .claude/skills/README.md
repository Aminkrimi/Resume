# Project skills

Design skills from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT, commit c184364), installed for Claude Code.

| Folder | Skill name | Use it for |
|---|---|---|
| taste-skill | design-taste-frontend | Main anti-slop frontend skill for landing pages, portfolios and redesigns |
| redesign-skill | redesign-existing-projects | Auditing and upgrading an existing UI |
| soft-skill | high-end-visual-design | "Expensive agency" look: fonts, spacing, shadows, motion |
| minimalist-skill | minimalist-ui | Clean editorial / monochrome style |
| brutalist-skill | industrial-brutalist-ui | Swiss-grid, terminal-style brutalism |
| output-skill | full-output-enforcement | Forces complete code output (no placeholders) |

Update: `npx skills add https://github.com/Leonxlnx/taste-skill`, or re-copy the SKILL.md files.
